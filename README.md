## ✦ Organização

Cada recurso tem uma pasta própria, com uma página `README.md` para apresentar o objetivo, as funcionalidades, a utilização e a origem do projeto. Quando incluídos, os ficheiros do resource estão separados por pasta, preservando a estrutura necessária à instalação no MTA.

```text
MTA/
├── assets/
│   └── mta-banner.svg
├── Painel-Administracao-MTA-Portugal/
│   ├── README.md
│   ├── LICENSE-MTA.txt
│   └── admin/
│       ├── meta.xml
│       ├── client/
│       ├── server/
│       └── ...
└── README.md
```

> **Distribuição:** a compilação/ofuscação de Lua dificulta a leitura direta, mas não é uma garantia de inviolabilidade. Não colocar credenciais, segredos ou dados pessoais nos resources publicados.
